# 멍냥노트 스크린샷

사용자가 제작한 App Store 홍보용 스크린샷 5장입니다. 원본 이미지를 수정하지 않고 지정된 파일명으로 보관합니다. 현재 앱은 **TestFlight 준비 중**입니다.

## 문서 연결

- [GitHub 포트폴리오 README](../README.md): `screenshots/파일명` 경로로 5장 표시
- [프로젝트 상세](../docs/portfolio.md): `../screenshots/파일명` 경로로 같은 이미지 표시
- 이 안내의 이미지 링크는 같은 폴더의 파일명을 사용합니다.

홍보용 이미지에 표시된 이름·날짜·기록은 화면 예시입니다. 이미지 교체 시 파일명과 상대 경로를 유지하면 문서 연결을 그대로 사용할 수 있습니다. 사진 출처는 [샘플 이미지 출처](../docs/sample-image-provenance.md)를 참고하세요.

## 화면에 담긴 구현

홈은 공용 한 줄 메모와 케어 체크 상태, 기록은 날짜별 목록, 리포트는 저장 기록의 집계, 영양제는 급여 정보·알림, 펫상식은 앱 내장 콘텐츠를 보여줍니다. 이미지에 표시된 데이터는 화면 예시입니다. 샘플 생성·원본 복원 방식은 [구현 상세](../docs/portfolio.md)와 [문제 대응](../docs/troubleshooting.md)에 설명했습니다.
